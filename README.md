# Deep Learning Experiments and Projects

A portfolio of hands-on deep-learning implementations built while studying neural networks, computer vision, TensorFlow, and Keras.

## Focus

This repository demonstrates progression from core neural-network concepts to custom layers, CNN architecture experiments, and an applied aircraft image project.

| Notebook | Focus |

## Recommended environment

```bash
python -m venv .venv
```

Activate the environment and install the main dependencies:

```bash
pip install -r requirements.txt
jupyter notebook
```

Notebook-specific dependencies and compatible TensorFlow versions may vary. For research-grade reproduction, each major project should eventually be moved into its own repository with pinned versions, a fixed random seed, exported metrics, and documented dataset provenance.

## Portfolio notes

This is a learning-and-experiment repository. The aircraft notebook is the strongest applied project and should be reviewed first. New end-to-end work—such as the 13-band EuroSAT multispectral classifier—should use a dedicated repository rather than being added as another unrelated notebook here.
